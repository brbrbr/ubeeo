- Er is een gebruiker nodig met rechten om veld-waardes te mogen bewerken en artikelen mogen aanpassen en verwijderen.
   - Geef de gebruiker de rol van redacteur en pass de rechten aan.
- de plugin kan de code die nodig is voor het kandidaten portaal automatisch toevoegen aan een artikel:
    - Maak hiervoor een artikel en een single artikel menu aan voor het kandidaten portaal. Deze mag niet in de categorie die hierboven aangemaakt is!
- voor het uitvoeren van de cron job kun je een Geplande taak aanmaken of een externe CRON via een https request gebruiken. Voor de https request wordt gebruik gemaakt van de sleutel die ook voor de geplande taken Web Cron gebruikt wordt:
    - Ga naar de instellingen voor de Geplande taken
    - Schakel de Web Cron in.
    - Opslaan
    - Eventueel kan de Web Cron weer uit.
